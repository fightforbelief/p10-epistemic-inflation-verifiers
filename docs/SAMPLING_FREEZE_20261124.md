# Confirmatory sampling and primary analysis

This amendment to v0.3 records the researcher's 24 November 2026 decision to prepare a result paper, exclude the union of both pilots, and release the blinded roster after the synthetic analysis and upstream MiniCheck checks. It moves library parity out of the sampling gate. Each secondary software workflow still requires its 50-pair real-library check before reporting. Model scoring requires a hashed human-label return and separate researcher authorization. The completion record and file hashes are in the sampling manifest.

## Population and order

The two pilot rosters each contain 300 unique documents and share 261. Excluding 339 leaves 4,844 of the 5,183 SciFact documents before edit eligibility. Keep the corpus hash, rule v2 hash, 8–60 word filter, seed and category order from v0.3. All unused pilot sentences in those documents are excluded as well.

Allocate disjoint document queues in the order scope, hedge, causal, quantifier and modal. Reserve each queue up to its v0.3 cap before allocating the next. Within each queue use the first eligible sentence per document in SHA-256 order. This defines the population for each later stratum. The primary estimands weight sampled documents equally within edit class. Report the flow from each assigned queue through the stopping prefix, well-formed edits and valid judgments. Generalization beyond this rule-eligible population requires additional evidence.

The annotator traverses each queue in order. For hedge stop at the 150th valid row or the end of the 220-row queue. For modal stop at 200 or the end of 330. Complete each other queue. Extra reserve rows after a stop were never observed. Do not replace broken rows outside this scheme. A valid primary row requires Q1 ok or minor, Q2 yes and Q3 no. Scope additionally requires Q4 generic. The 60 weaken and 60 negate human checks are taken by deterministic hash within the guaranteed-to-be-processed prefix of each queue pooled together. This keeps controls available before any label is known. A control may share its source with its focal edit and with the other control.

## Scoring, units and gates

Use MiniCheck's pinned upstream public scoring method, including its sentence splitter, checkpoint refs and chunking. One unit is one processed focal document. For both MiniCheck contexts and both generic/strength judge prompts score identity and every available negate on the same processed roster. Score focal edits and matched weaken controls on valid rows for the primary analysis. The additional rows for descriptive sensitivity sets remain a separate scoring ledger. Log exclusions, clipping of source evidence, and repeated calls separately. The 120 hand-checked controls diagnose edit quality. The configuration gate uses all available paired negative controls as specified in v0.3. Its intended property is lack of support. For a sentence with “may”, a categorical negative forecast can be compatible with a possible outcome and needs no contradiction interpretation.

At each configuration compute identity acceptance on documents with an eligible negate, and the paired identity-minus-negate difference on jointly observed pairs. The minimum is 150 complete pairs. More than 2% missing across planned cells prevents interpretation. Show the denominator and missing count for each endpoint. The score ledger must enumerate each scheduled call, including explicit nulls for failed calls. Model probabilities are thresholded strictly above 0.5 for MiniCheck and at or above 0.5 for judges. H1 uses the abstract gate and both class-specific one-sided exact lower limits. H2 uses both premise gates on the same model and pairs abstract minus sentence decisions on valid modal documents. H3 requires both prompt configurations to pass and pairs generic minus strength decisions. The H3 benefit is measured on valid modal documents. The identity cost uses all valid documents and the weaken cost uses valid documents with an available weaken. Each cost must be at most five percentage points. Controls with a broken or disputed interpretation will also be described separately.

All six hypotheses use one-sided alpha 0.05/6. A conjunction such as H1 succeeds only if both constituent tests succeed. A minimum-denominator or missingness failure is reported as uninterpretable and cannot count as support for a hypothesis. Paired differences resample independent documents as 10,000 multinomial draws on the three observed difference values. The lower limit is the lower order statistic at alpha, with RNG seed 20261124. For a constant difference, subtract an exact upper bound on the loss probability from an exact lower bound on the gain probability, each at alpha/2. Report rates, the two discordant counts and denominators alongside all decisions. The percentile bootstrap is an approximate interval. Supporting statements cannot be inferred from a high acceptance rate without the corresponding controls.

The held-out documents have supplied no human validity labels or model outputs when these choices are made. Estimated annotation time is about nine hours and depends on yield. Using one hypothesis-aware human labeler makes measurement error a limitation even with score blinding.
