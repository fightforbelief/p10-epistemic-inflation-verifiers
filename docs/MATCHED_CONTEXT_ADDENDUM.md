# Matched context on the 200 valid modal edits

The original analysis plan included donor-text padding as an interpretive comparison. The researcher authorized 400 local MiniCheck calls on 24 November after reading the primary outcomes and before seeing donor-condition outcomes. All 200 eligible modal claims enter for both pinned encoders. This extension reports descriptive estimates. The six frozen primary tests retain their original definitions and decisions.

For each source, use the existing matched_filler function. Preserve the exact qualified source sentence at its original whitespace-word offset and the total word count of its abstract. Obtain surrounding words from hash-ranked SciFact abstracts outside both pilot rosters and every issued queue, continuing into the next donor when necessary. The source- and document-specific hash fixes donors before scoring. Donor sentences can be cut at the boundary. Record donor IDs, word offset, full-input tokenizer lengths, actual scored chunks and clipping on the research machine.

Compare all three presentations on the same complete document triples at the official strict 0.5 threshold. Report both directions of switching and descriptive paired 95% intervals. Resample documents with seed 20261124 and 10,000 draws, using simultaneous exact bounds for a constant paired difference. Additional diagnostics restrict to triples scored in one chunk in all three presentations and repeat the abstract-minus-filler comparison at thresholds 0.1 through 0.9. These diagnostic choices were specified after the primary findings and before the donor scores. The added condition has one donor construction per source. Word matching leaves differences in subword length, topic, syntax and coherence.

From the project root use the project Python environment and set NLTK_DATA to data/nltk_data. Run scripts/modal_context_control.py score, then scripts/modal_context_control.py report. The scoring step makes at most one new call per eligible document per encoder in an uninterrupted run and uses SQLite checkpoints. The report reads the primary ledger and the added scores. Input texts and donor IDs stay in the research workspace.

After unblinding the donor results, the report also compared the two model-specific abstract-minus-filler contrasts within each document. The bootstrap samples the observed five possible difference values (−2 to +2) jointly across the two encoders. This post hoc analysis is marked in the aggregate.
