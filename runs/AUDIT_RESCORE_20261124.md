## 6. GO 裁定记录（2026-11-24）

- **问题：** README 的 NO-GO 条款"所有膨胀类型在 sentence 前提下的 AUROC 都 ≥ 0.90"没有写明是全体核查器还是逐个核查器。
- **裁定：** 研究者选择按全体读，即要求所有核查器都满足才触发。DeBERTa-large、nli-deberta-base、MiniCheck-DeBERTa 都不满足，所以不触发，**维持 GO 到 Gate 0**。
- **性质：** 这是看过结果之后的解释，不是事先写明的。按逐个读，MiniCheck-RoBERTa 会触发。对外描述试点时必须同时披露这两点。
- **对正式协议的约束：** 不再沿用这一条款。它对 weaken 也给出 1.000，测的是"有没有改动"。新规则要写明汇总范围，并用 weaken 作参照。
- GO 只表示继续做 Gate 0，**不等于冻结正式协议**。
